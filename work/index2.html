EcoFurnish — Sustainable E-Commerce Platform

A full-stack, eco-conscious e-commerce web application designed for modern living. Engineered with real-time eco-impact tracking, multi-currency localization, responsive mobile-first architecture, an admin portal, and an automated Telegram crash logging bot.

Eco-Impact Tracking & Dynamic Catalog

Built a modular product catalog equipped with category/room filtering, search capabilities, and instant multi-currency conversion. Each item dynamically highlights its environmental impact (e.g., kg of plastic diverted) to promote eco-friendly purchasing choices.

Cart, Wishlist & Dark Mode

Engineered client-side state management for fluid add-to-cart operations, quantity updates, and persistent wishlists. The UI seamlessly adapts to user preferences with a built-in dark/light mode toggle across desktop and mobile.

End-to-End Checkout Flow

Engineered a complete, secure buyer journey. This includes automated email verification for new users, seamless payment processing through the Chapa gateway, and dynamic order confirmation receipts directly in the application.

Automated Telemetry & Admin Controls

Integrated an Admin Management Suite for real-time inventory control alongside a dedicated Telegram Bot webhook that instantly dispatches server crash logs, daily digests, and diagnostic alerts directly to the developer.

Viral Referral & Growth Engine

Developed an integrated referral ecosystem allowing registered users to generate unique invitation links, monitor successfully converted purchases, and unlock reward tiers.
